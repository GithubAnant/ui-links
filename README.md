# ui.anants.studio

A clean Next.js directory for UI bookmarks, inspiration, component libraries, typography, motion references, and design tools.

## Edit links

All links live in `data/links.ts`. Add new entries to `uiLinks` with a category, tags, and a short description.

## Run locally

```bash
npm install
npm run dev
```

The app is designed for `https://ui.anants.studio`, but it runs locally at `http://localhost:3000`.
